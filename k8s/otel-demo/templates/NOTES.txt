The synthetic shop is running in namespace {{ .Release.Namespace }} on cluster {{ .Values.clusterName }}.

  kubectl get pods -n {{ .Release.Namespace }}
  kubectl logs -n {{ .Release.Namespace }} deploy/otel-collector

Telemetry lands in Fabric database {{ .Values.kusto.database }} within a few minutes. Check it in KQL:

  OTELTraces
  | where StartTime > ago(15m)
  | where tostring(ResourceAttributes["k8s.cluster.name"]) == "{{ .Values.clusterName }}"
  | summarize Spans = count() by SpanName
